# Dataset folder

Place your labelled image dataset here using this structure:

```text
data/
  train/
    class_one/
    class_two/
  val/
    class_one/
    class_two/
  test/
    class_one/
    class_two/
```

Class folder names must match across all splits. This repository intentionally
does not include third-party images. Check dataset licence and attribution terms.
